# HashZap - Chat em tempo real com Flet

Este é um projeto de chat simples criado com a biblioteca [Flet](https://flet.dev), que permite construir interfaces interativas com Python rodando direto no navegador.

## 🔧 Funcionalidades
- Interface visual com Flet
- Campo de nome de usuário
- Envio e recebimento de mensagens em tempo real
- PubSub interno para comunicação entre sessões
- Execução no navegador (`ft.WEB_BROWSER`)

## 💡 O que aprendi
- Criação de interfaces com Flet
- Lógica de chat em tempo real
- Manipulação de eventos e PubSub com Python
- Deploy leve de apps Python no navegador
